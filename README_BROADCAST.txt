CCC BROADCAST CENTER — PHASE 1

Upload index.html, styles.css, app.js, broadcast.js, announcements.json, and feed.xml to the ROOT of the existing GitHub Pages repository. Replace only the first three files; add the last three. Keep all other files unchanged.

To publish a new announcement: edit announcements.json and add an entry at the beginning of posts with unique id, title, ISO UTC date, category, body, and optional url. Then update feed.xml with a corresponding RSS item. Both files must be updated for the website and RSS to agree. Future phase: automate RSS generation from JSON.

This release is a PUBLIC READER, not a web-based editor, automated social publisher, or secured login. GitHub repository permissions control publishing. The welcome announcement is sample content, not evidence of a real prior broadcast.

If an installed service worker caches older files, reload the app or clear the site cache after deployment.
